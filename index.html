设置高德 Key

附近餐馆是从高德地图查真实门店，所以要一个「Web服务」类型的 Key。免费，申请大约 5 分钟：

  1. 打开 高德开放平台控制台 ↗，手机号注册并完成个人实名认证（免费）。
  2. 「应用管理 → 我的应用 → 创建新应用」，名字随便写。
  3. 点「添加 Key」，服务平台选「Web服务」（不要选 JS API、Android 或 iOS）。
  4. 复制那串 32 位字符，贴到下面。

Key 只存在这台设备的浏览器里。如果这个页面是公开的，不要把 Key 写进文件再上传：谁打开都能在请求里看到它。不用了可以在下面清除。
