# 饭点 · 今天吃什么（在线版）部署说明

## 这个文件夹里有什么

| 文件 | 作用 |
| --- | --- |
| `index.html` | 整个应用（样式和脚本都在里面，单文件） |
| `manifest.webmanifest` | 添加到手机主屏幕时的名字、颜色、图标配置 |
| `icon.svg` / `icon-180.png` / `icon-512.png` | 应用图标 |
| `README-部署.md` | 本说明 |

这几个文件放在同一个目录下就能跑：不需要 Node、不需要构建、不需要数据库。任何静态托管（GitHub Pages、Netlify、Cloudflare Pages）都可以。

---

## 关于高德 Key（重要，先看这段）

页面里**没有内置任何 Key**。第一次在这台设备上打开时，点页面里的「设置 Key」，粘贴你自己的高德「Web服务」Key，它会存在这台设备的浏览器里，以后自动带上。

- **为什么不能写死在页面里**：查门店时浏览器必须把 Key 发给高德，写在页面里就等于公开给所有人看（开发者工具里一目了然），你的每日额度会被别人用掉。
- 换手机、换浏览器、清理站点数据后，需要重新粘贴一次。
- 页面里随时能看到状态（「还没设置高德 Key / 高德 Key 已设置」），点「设置 Key」可以更换或清除。
- 想自己申请：<https://console.amap.com/dev/key/app> → 手机号注册并完成个人实名认证（免费）→ 创建应用 → 添加 Key 时**服务平台必须选「Web服务」**，并且**不要开 IP 白名单**（手机和电脑的出口 IP 每次都不一样）。

> 如果哪天真要写死一个 Key（比如只给自己用、不在意公开），把 `index.html` 里的 `const AMAP_DEFAULT_KEY=''` 改成你的 Key 即可；但请记住它对人可见。

## 部署到 GitHub Pages

1. 登录 GitHub，右上角 `+` → **New repository**。
2. 仓库名填 `fandian`，选 **Public**，不要勾 “Add a README file”，点 **Create repository**。
3. 在仓库页点 **Add file → Upload files**，把本文件夹里的 5 个文件（`index.html`、`manifest.webmanifest`、`icon.svg`、`icon-180.png`、`icon-512.png`）一起拖进去，点 **Commit changes**。
4. 打开仓库的 **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/ (root)**，点 **Save**。
5. 等 1～2 分钟，刷新 Settings → Pages，顶部会出现地址：
   `https://<你的用户名>.github.io/fandian/`
6. 手机浏览器打开这个地址 → 菜单里选「添加到主屏幕」，就会像 App 一样有图标。

**更快的替代方案**：把整个 `饭点-在线版` 文件夹拖到 <https://app.netlify.com/drop>，几秒就能得到一个 https 链接（需登录 Netlify 账号）。Cloudflare Pages 的“直接上传”也一样。

> 为什么一定要 HTTPS？手机浏览器**只在安全上下文里给定位权限**；`file://` 本地文件或 `http://` 局域网地址通常拿不到定位，只能用手动地点。部署到 https 后「定位」才会弹权限框。

## 手机上怎么用

1. 打开链接 → 第一次先点「设置 Key」，粘贴你的高德 Web 服务 Key（只做一次，之后自动记住）。
2. 点「定位，看看附近吃什么」→ 允许定位 → 出 3 家店（1 家推荐 + 2 家备选）。
3. 想看别的：点「换 3 家看看」；这家不对胃口：点「不想去这家」，之后可用「恢复暂不推荐的店」找回。
4. 想省钱：把「地图人均预算」改成 25 元内，会先排便宜的小馆。
5. 定下来：点「就吃这家」→ 确认 → 页面出现「今天午饭/晚饭，就去这家」。
6. 出发：点「导航去」→ 选 步行 / 骑行 / 驾车 → 选高德 / 百度 / 苹果 / Google 地图。手机上装了对应 App 会直接跳进 App 导航。
7. 定位不准或不在现场：展开「手动选一个地点」，输入学校、商圈或小区名，用它来找店。

记录（吃过的、收藏的、不想去的）存在**自己设备的浏览器**里，换设备或清浏览器数据前，用「备份与使用说明 → 下载备份」导出一份 JSON。

## 以后改了文件怎么更新

重新上传同名 `index.html` 覆盖即可（GitHub 网页上点文件 → 铅笔图标编辑，或再拖一次上传），Pages 会自动重新发布。用户的记录不受影响。

## 已知边界（页面上也写明了）

- 门店资料来自高德，人均、评分、营业时间可能过期；**这家今天开不开门，打个电话最准**（卡片里有电话可以直接拨）。
- 排序是“菜系/招牌关键词 + 评分 + 距离 + 你的口味偏好”的启发式，不是菜谱级推荐；“米饭 / 面食 / 简餐”分类也是按门店类型和名称推断的，可能不完全准。附近确实没有甜口店时，页面会直说，并按评分和距离排。
- 一次只取最近的 25 家（高德周边搜索单页上限），所以“25 家可去”是候选池，不是全域总数。
- 导航坐标做了坐标系换算（高德 GCJ-02 / 百度 BD-09 / 苹果与 Google WGS-84），不会偏到隔壁街；但门店入口位置仍以地图 App 为准。
